# Экспорт пакета диагностики

Кнопка «Диагностика» на странице логов в один клик экспортирует zip для сообщений об ошибках. Перед записью открывается предпросмотр со списком файлов и обезличенных полей. Экспорт только читает состояние системы и файлы конфигурации — сбой экспорта не влияет на работающий прокси.

## Формат пакета

Zip записывается рядом с логами приложения, имя `snishaper-diagnostics-<метка времени>.zip`, содержит:

| Файл | Содержимое |
|---|---|
| `diagnostics.json` | время экспорта, версия, платформа, состояние сервиса/прокси/системного прокси/TUN, результат самопроверки, список файлов |
| `settings.json` | **обезличенная копия** `config/settings.json` |
| `rules.json` | **обезличенная копия** `rules/config.json` |
| `logs.txt` | последние 500 строк логов приложения из памяти (обезличено) |

Верхний уровень `diagnostics.json`:

```json
{
  "generated_at": "метка времени RFC3339",
  "version": "версия приложения",
  "diagnostics": { "version": "...", "platform": "...", "system_proxy": {...}, "tun": {...} },
  "self_check": { "ok": true, "checks": [ { "name": "service", "ok": true } ] },
  "files": [ { "name": "settings.json", "size": 123, "description": "..." } ]
}
```

## Правила обезличивания

Перед экспортом копии конфигураций и текст логов проходят следующую обработку (исходные файлы не изменяются):

- **Чувствительные ключи**: строковые значения ключей, содержащих `api_key` / `apikey` / `token` / `secret` / `password` / `authorization` (без учёта регистра, по подстроке), заменяются на `[REDACTED]`.
- **Учётные данные в URL**: userinfo в `scheme://user:pass@host` заменяется на `[REDACTED]`.
- **Токены в параметрах запроса**: значения `?api_key=…&token=…&secret=…&password=…` заменяются на `[REDACTED]`.
- **Bearer-токены**: часть `Bearer <token>` после слова Bearer заменяется на `[REDACTED]`.
- Не разбираемые файлы конфигурации включаются как текст после того же текстового обезличивания (проблема видна, а не молча отброшена).

## Известные ограничения

- Обезличивание основано на именах полей и типовых шаблонах; **перед отправкой проверьте zip самостоятельно**.
- Домены, правила и списки IP — необходимая диагностическая информация, они не обезличиваются.
